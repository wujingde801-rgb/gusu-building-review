# 工程建设标准化信息网按需读取

用户指定 https://www.ccsn.org.cn/newweb/standardQuery 为主要线上标准来源。无需用户事先批量下载；按项目检索，长期仅保留链接与引用信息。网站接口来自公开前端调用，非官方承诺的稳定API，结构变化时应报失败并改用网站UI或发布机关正式全文。

## 工作时的入口

使用当前可用Python；提取PDF文字需要pypdf，先检查当前解释器是否已安装。脚本调用系统curl（验证TLS，不需账号、Cookie或浏览器控制）。在技能目录以外的新项目子目录保存链接与元数据，PDF及定位文本默认只写入临时工作目录（终端返回temporary_working_directory供阅读）：

```sh
python scripts/ccsn.py search GB55019
python scripts/ccsn.py fetch <检索结果Guid> --out <项目目录/online-standards/新目录>
```

1. 按标准编号或名称检索，核对返回名称、编号、日期及状态，选择匹配版本的Guid。关键词可用编号主体（如50500），避免空格格式造成漏检；不猜Guid或附件ID。不对全部目录批量遍历。
2. fetch默认在输出目录保存详情JSON和manifest（链接、访问时间、读取状态等），PDF和文字索引写入临时目录；读取阶段的哈希可保留，但线上意见校验不依赖它。仅用户明确要求长期归档时加 `--keep-fulltext` 才将全文保存在输出目录。没有全文或下载失败会非零退出；metadata_only、fulltext_failed都不能算已读全文。已存在目录拒绝覆盖。
3. **PDF取得不等于正文已读。** 先渲染所需页，例如 `pdftoppm -f 5 -l 5 -scale-to 1800 -png standard.pdf page`，再用图像工具查看。文本索引可能非空但乱码，不能只检查文本长度；可采用OCR定位，引用必须回看原页。记录实际已读页、印刷页、条号及必要上下文。manifest的visual_review保持not_started，不能用脚本替人宣称已读。
4. 每次工作至少实际完成本次所需标准的“搜索→详情→PDF→正文页视觉阅读”。记录到项目verification_log和依据记录；覆盖范围按实际已读页填写，不声称全库/全册已审。
5. 网站标记“现行”是线索，仍核验发布机关实施、修改、替代、废止公告及项目适用条件。检索摘要、目录、元数据不单独支撑条文结论。

## 失败与降级

- 浏览器控制或通用网页读取超时，优先运行上述按需脚本，不能据一次浏览器超时断言网站不可用。
- 脚本返回接口/网络错误，查看失败信息；仅对暂时超时做一次合理重试，再改用Chrome网站UI（搜索、详情、PDF）或发布机关官方全文。无结果与网络失败分开记录。
- 两条路径都未取得所需正文时，明确写“未取得全文”，保持insufficient；继续其余可开展审查，不要求用户下载全库。
- 不处理登录限制或验证码绕过，不关闭TLS验证。需要用户操作时说明具体阻碍。

## 证据与知识库边界

默认项目报告仅保留链接、名称编号、版本、条号及页码、核验日期和核验说明；临时PDF/定位文本只为实际阅读服务，阅读完可清理本次工具生成的临时文件。线上依据可直接走online校验，不要求B类入库。用户明确要求正式入库时再走知识库提案/确认流程。不在技能目录保存规范全文，不自动同步全站；不自动删除过去已交付资料。

2026-11-03实测：公开页面可取；公开表单查询与详情接口可用；GB55019-2021 PDF取得并实际查看物理第5页（印刷第2页）正文，20页。pypdf文本提取乱码，但渲染正文清晰。浏览器控制超时，已用直接公开读取路径完成。更多样例以本次工作区验证记录为准；这不是所有标准可用性或现行性保证。

同日新增脚本实测：GB55037-2022取得66页PDF，视觉查看物理第10页/印刷第6页；GB/T50500-2024取得95页PDF，视觉查看物理第10页/印刷第2页。两份抽查正文均清晰可读，未全册审读。

## 对外引用

将manifest.detail_url渲染为可点击标准名称，将manifest.pdf_url渲染为“标准全文”链接（仅成功取得并核对的附件）。同时保留编号、版本、条号和页码；不得仅把链接藏在JSON中。链接通常打开整份标准，不保证自动跳转到条文。
