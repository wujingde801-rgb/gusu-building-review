# 标准检索与官方核验入口（V1不预装有效规范）

本表仅用于发现来源，不是已激活的规则。2026-10-26检查了下列搜索入口及页面可发现性，未据此宣称该领域规范库完整。每个实际项目仍需打开正文、附件、变更/废止公告与保护名录，保存访问日期和原文定位。官方新闻、会议纪要不自动等同规范。

- 苏州市政府对应全文入口：
  https://www.suzhou.gov.cn/szsrmzf/gbdfxfg/202505/d2ae1c3185a14a7b9c4668415e4bdf4d.shtml
- 姑苏区政府（从站内查保护对象名录、保护规划与主管部门正式文件）：https://www.gusu.gov.cn/
- 国家标准与工程建设规范：优先住房城乡建设部公告/全文入口、国家标准信息公共服务平台；核对全文是否公开及版权，不从转载库批量下载付费全文。
- 历史建筑与文物分别核验：文物法及国家文物局、省/市文物主管部门；历史文化名城、街区及历史建筑另查相关正式保护法规、批准保护规划、名录和项目专项文件。

检索顺序：项目名称/名录编号 → 用户指定线上标准来源（本地地方正式资料补充） → 发布机关同名文件及实施/替代公告 → 正式全文 → 关联上位依据及过渡条款。查不到则记录“未取得”，避免以地方经验填补强制依据。网页可用不证明现行；搜索摘要更不能证明完整适用条件。


## 用户提供的补充标准检索入口

- 名称：工程建设标准化信息网。网址：https://www.ccsn.org.cn/ 。本次首页主办栏显示“住房和城乡建设部标准定额研究所”。
- 用途：本地资料不足时，用于查找工程建设标准名称、编号、版本、批准/施行信息，以及标准附件。具体适用性仍逐项判断，不以站点覆盖范围代替来源核实。
- 2026-10-26复测：本机网络首页HTTP 200；Chrome实际查询、详情和PDF附件显示均成功。网页读取工具仍超时、内嵌浏览器自动化读取亦超时，故有条件时优先使用本机浏览器或经授权的本机网络读取；失败不等于网站整体不可用。
- 查询入口：https://www.ccsn.org.cn/newweb/standardQuery 。首页支持按标准名称、编号或主编单位查询。可带参数 `?keyword=GB55019` 预填关键词，实际测试中需点击“搜索”并等结果加载，初始“暂无数据”不能立即解释为未收录。
- 已验证样例：GB55019 → 《建筑与市政工程无障碍通用规范》GB55019-2021；检索返回1条，详情显示批准日期、施行日期、编制单位等元数据，并显示20页PDF附件。
- 样例详情：https://www.ccsn.org.cn/newweb/standardQuery?guid=87c30386-4d8d-4565-8bd8-4d3ce9211509&showDetail=true 。附件已实际视觉显示，但未逐页审读、未验证所有标准均有全文、未测试批量下载或建立自动同步。该样例不是对截至本次的现行性完整法律核验。
- PDF阅读：样例附件含图像化正文，浏览器辅助功能文本提取曾报错但页面图像可见；需要逐页视觉阅读或OCR，不能因文字提取失败判断全文不可用。
- 取得具体标准时记录详情URL、附件定位、版本、发布/实施信息及访问日期，按项目适用时点核实修订、替代、废止和过渡公告。若取得正式原文，可走知识库资料提案流程，不把网页条目自动改为有效B类依据。
- 历史记录：早先仅网页读取及内嵌浏览器尝试超时，故标记未验证；本次已完成本机网络及Chrome实际功能复测。知识库现有6份待核实资料的状态不因本网站连通性验证而改变。

## 工作时接入方式（2026-11-03更新）

实际查询与全文读取优先按 [线上标准接入](ccsn-access.md) 执行，使用 `scripts/ccsn.py` 从网站公开前端同源接口按需读取。该路径已实际取得PDF并视觉阅读正文，独立于浏览器控制；浏览器超时不应阻断全部标准检索。长期默认只保留链接与引用信息；原文按需临时读取，不批量下载、不自动正式入库。
